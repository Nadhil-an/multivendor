1. Introduction

With the rapid development of digital technologies, many everyday services are transitioning from traditional manual processes to online systems. Web-based applications have become essential tools for improving efficiency, convenience, and accessibility in various sectors including education, commerce, and service industries.

UniEats is a specialized web-based food pre-ordering system designed specifically for college campuses. The system allows students to browse food stalls, view menus, and place orders online before arriving at the stall.

2. Technology Stack

The platform follows a modern client-server architecture using the following technologies:

Python 3.10+ Django 5.2 PostgreSQL Razorpay API HTML5 / CSS3 JavaScript SMTP Mail Server Django REST Framework

3. Problem Statement & Scope

The Problem

Students in university food courts frequently experience long waiting times due to manual ordering processes. During peak hours, the large number of students ordering food simultaneously leads to overcrowding and inefficient service. The lack of a digital ordering system prevents students from placing orders in advance, resulting in unnecessary delays.

The Solution (Scope)

UniEats provides a digital ecosystem for campus food courts. The system enables:

  • Online food browsing and pre-ordering for students.
  • Dynamic menu and category management for vendors.
  • Secure online payment processing via Razorpay.
  • Automated order tracking and token generation.

4. System Design & Architecture

UniEats follows a Role-Based Access Control (RBAC) model with three primary user types:

  • Administrator: Manages the platform, approves vendors, and monitors overall activity.
  • Vendor (Restaurant Owner): Manages stall details, menu items, pricing, and order status.
  • Student (User): Browses vendors, manages a shopping cart, and completes purchases.

Database Schema (Logical Models)

The system utilizes a relational database (PostgreSQL) with the following core entities:

Table NamePurpose
UserPrimary authentication and role management.
UserProfileStores address, phone, and profile images.
VendorStores information about the food stall and approval status.
OpeningHourManages vendor availability by day and time.
CategoryGroups food items for better menu navigation.
FoodItemStores item names, descriptions, pricing, and availability.
CartTemporary storage for student selections before purchase.
OrderRecords successful transactions and generates pickup tokens.
PaymentLogs Razorpay transaction IDs and payment status.

5. Security Measures

Several security mechanisms were implemented to ensure data integrity and user trust:

  • Secure Authentication: Uses PBKDF2 hashing for passwords.
  • CSRF Protection: All requests are protected against Cross-Site Request Forgery.
  • Role-Based Access: Strict permission checks at the view level ensure vendors cannot access each other's data.
  • Payment Hashing: Sensitive payment data is handled externally by Razorpay with secure callback verification.
  • Admin Honeypot: Detects unauthorized attempts to access the management portal.

6. Future Scope

While the current system is functional, several enhancements are planned for the future:

  • Mobile App: Developing native mobile versions using the built-in REST API.
  • QR Verification: Vendors can scan a customer’s QR code to mark orders as "Collected."
  • AI Analytics: Providing vendors with insights into their most popular dishes and peak sales hours.

7. Conclusion

The UniEats system provides an efficient solution for managing food ordering within university campuses. By enabling students to pre-order food online, the system reduces waiting times and improves the overall dining experience. Through its role-based design and scalable architecture, the system ensures convenience for users and efficiency for vendors.
